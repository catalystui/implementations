# C / C++

CatalystUI libraries for C and C++ provide native interfaces that can be used in applications and other libraries.

## Libraries

| Library | Description | Source |
| --- | --- | --- |
| [Core](/implementations/lib-core-c/) | Foundational C ABI types and libraries for memory management, text encoding, and relational collections. | [GitHub](https://github.com/catalystui/lib-core-c) |
| [Aether](/implementations/lib-aether-c/) | Cross-platform C ABI library for native system-level bindings and operating system functionality. | [GitHub](https://github.com/catalystui/lib-aether-c) |
| [Crystal](/implementations/lib-crystal-c/) | Cross-platform C ABI library for windowing and system interaction, implementing the Window layer of the CatalystUI model. | [GitHub](https://github.com/catalystui/lib-crystal-c) |
