# Getting Started

CatalystUI implementations are the libraries, tools, and other software that bring the principles of the [CatalystUI Model](/model/) and its [Specifications](/specifications/) into practice.

Each project has its own purpose and may be used independently or alongside other projects in the ecosystem. Implementations may differ across programming languages while sharing the same foundational concepts.

## Explore the Ecosystem

The [Ecosystem](/ecosystem/) organizes CatalystUI projects by programming language. Each library provides its own documentation, including its installation instructions, supported features, and API reference as they become available.

## Documentation

Implementation documentation is maintained alongside the source code of each library. Where versioned documentation is available, the version selector allows you to view documentation for the corresponding release.
